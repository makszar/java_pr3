## Как работает код

### Геометрические фигуры

`Shape` является абстрактным классом. Он хранит общие свойства фигур: цвет `color` и признак заливки `filled`. Получать и менять эти свойства позволяют геттеры и сеттеры.

В `Shape` объявлены два абстрактных метода: `getArea()` и `getPerimeter()`. У каждой фигуры свои формулы, поэтому вычисления реализованы в дочерних классах.

| Класс | Данные | Площадь | Периметр |
| --- | --- | --- | --- |
| `Circle` | Радиус `r` | `Math.PI * r * r` | `2 * Math.PI * r` |
| `Rectangle` | Ширина `w` и длина `l` | `w * l` | `2 * (w + l)` |
| `Square` | Сторона `a` | `a * a` | `4 * a` |

`Square` наследуется от `Rectangle`. При изменении ширины или длины квадрата обе стороны меняются одновременно. Поэтому после вызова `setWidth()` или `setLength()` объект остается квадратом. Вычисление площади и периметра он наследует от прямоугольника.

В `TestShape` создаются круг радиусом `5.5`, прямоугольник со сторонами `1` и `2`, квадрат со стороной `6.6`. Они помещаются в массив `Shape[]`. Цикл выводит описание, площадь, периметр, цвет и признак заливки каждой фигуры.

Это пример полиморфизма: ссылка имеет общий тип `Shape`, но Java вызывает метод того объекта, который за ней находится. Для круга выполняется расчет круга, для прямоугольника выполняется расчет прямоугольника.

### Движущиеся объекты

Интерфейс `Movable` содержит четыре метода: `moveUp()`, `moveDown()`, `moveLeft()` и `moveRight()`. Каждый класс с `implements Movable` должен реализовать эти действия.

`MovablePoint` хранит координаты и скорость по двум осям. Движение изменяет координаты на значение скорости. Используются экранные координаты: при движении вверх `y` уменьшается, при движении вниз увеличивается.

`MovableCircle` хранит радиус и объект точки центра. Его методы передают команду движения этой точке.

`MovableRectangle` хранит две точки: верхний левый и нижний правый углы. При движении перемещаются обе точки. Метод `hasSameSpeed()` проверяет, совпадают ли их скорости по обеим осям. Если скорости различаются, конструктор отклоняет создание прямоугольника. Переданные точки копируются, чтобы их внешнее изменение не нарушило работу объекта.

В `TestMovable` точка, круг и прямоугольник помещаются в массив `Movable[]`. Программа перемещает каждый объект вверх и вправо, затем вниз и влево. В итоге он возвращается в исходное положение. Отдельно проверяется попытка создать прямоугольник с разными скоростями углов.

## Какие классы и объекты используются

| Класс или интерфейс | Назначение |
| --- | --- |
| `Shape` | Общая основа геометрических фигур |
| `Circle`, `Rectangle`, `Square` | Конкретные фигуры с расчетом площади и периметра |
| `TestShape` | Демонстрация фигур и полиморфизма |
| `Movable` | Общий набор методов движения |
| `MovablePoint` | Точка, которая меняет свои координаты |
| `MovableCircle` | Круг, содержащий движущуюся точку центра |
| `MovableRectangle` | Прямоугольник, содержащий две движущиеся точки |
| `TestMovable` | Демонстрация движения и проверки скоростей |

Объекты `Shape` напрямую не создаются, поскольку класс абстрактный. Создаются только его конкретные наследники. У движущегося круга и прямоугольника есть вложенные объекты точек. Такое объединение объектов называется композицией.

## Разбор ошибок из методички

В исходном примере есть строки, которые не компилируются:

- `new Shape()` пытается создать объект абстрактного класса.
- `s1.getRadius()`, `s3.getLength()` и `s4.getSide()` вызывают методы, которых нет у типа ссылки `Shape`.
- `r2.getSide()` вызывает метод квадрата через ссылку типа `Rectangle`.

Для доступа к специальным методам требуется приведение к подходящему подклассу, например `((Circle) s1).getRadius()`. Приведение меняет тип ссылки, но не сам объект. Если реальный объект не соответствует указанному типу, возникнет `ClassCastException`. В программе использованы корректные приведения.

## Запуск

Нужен JDK 17 или новее. В IntelliJ IDEA нужно выбрать JDK, отметить `src` как Sources Root и запустить `TestShape` либо `TestMovable` через `main`.

Сборка из терминала: `sh build.sh` в Linux или `build.bat` в Windows.

```bash
java -cp out ru.mirea.pr3.shapes.TestShape
java -cp out ru.mirea.pr3.movable.TestMovable
```
